- **Tech Stack:** `React 19`, `TypeScript`, `Tailwind CSS v4`, `Node.js`, `Express`, `MongoDB`, `Cloudinary`, `Nodemailer`.
- **Live Demo:** [cathomestay.studio](https://cathomestay.studio)
